# fddm-fpt

Closed-form first-passage density for the full DDM — across-trial variability in drift
(normal), starting point (uniform) and non-decision time (uniform) — with its gradient in the
same call. One C++ core, thin R and Python wrappers, drop-in parametrizations for HSSM,
rtdists and WienR.

The six-parameter density needs no numerical integration; only the non-decision window keeps a
single fixed 1-D quadrature. See `../paper/main.tex` for the derivation and `../notes/` for the
working note.

```
core/     ddm_sz.{cpp,h}   the whole implementation; Faddeeva.{cc,hh} vendored from
                           ab-initio.mit.edu/Faddeeva (MIT)
python/   ddmsz.pyx        Cython wrapper, ddmsz.full_ddm in HSSM's parametrization
R/        ddmsz.R          .Call wrapper, no Rcpp; ddm_sz and ddm_rtdists
```

## Build

```bash
make          # core self-check, then both wrappers, each with its own check
make core     # c++ -O2 -std=c++11 -DFDDM_TEST ddm_sz.cpp Faddeeva.cc -o check && ./check
make py       # cythonize -3 -i ddmsz.pyx && python check.py
make r        # R CMD SHLIB && Rscript ddmsz.R
```

## Use

Python, HSSM's `full_ddm` parametrization (barriers at ±a, `z` and `sz` relative, `t` the
centre of the non-decision window, `response > 0.5` the upper barrier):

```python
import ddmsz
f, df = ddmsz.full_ddm(rt, response, v=1.2, a=0.75, z=0.45, t=0.3, sz=0.1, sv=0.8, st=0.12)
# f: (n,)   df: (n, 7), columns ddmsz.PARAMS = (v, a, z, t, sz, sv, st)
```

Lower barrier with the paper's own parameters, `w` relative and `sz` its full width:

```python
g, dg = ddmsz.density(t, nu, eta, a, w, sz)              # dg: (n, 5) rows nu, eta, a, w, sz
f, df = ddmsz.density7(t, nu, eta, a, w, sz, t0, st0)    # df: (n, 7), adds t0, st0
```

R, rtdists' parametrization (`a` the full separation, `z` and `sz` absolute, `t0` the lower
edge of the window):

```r
source("ddmsz.R")
r <- ddm_rtdists(rt, "lower", a = 1.1, v = 1.3, t0 = 0.25, z = 0.6, sz = 0.2, sv = 0.9, st0 = 0.15)
r$density                    # (n,)
r$gradient                   # 7 x n, rows a, v, t0, z, sz, sv, st0
ddm_sz(rt, v, sv, a, w, sz)  # WienR's relative (w, sz); ddm_sz7 adds t0, st0
```

`st0 = 0` returns the six-parameter density rather than dividing by zero, and a starting-point
range below 0.01 switches to a five-node average of the fixed-start density, which keeps the
`w` and `sz` derivatives accurate as the range closes.

## Checks

`make` runs all of them:

| check | against | worst |
|---|---|---|
| `core/check` | WienR, 353 sets of the fixed grid | 4.8e-10 |
| `core/check` | WienR, 1987 published parameter sets | 4.9e-11 |
| `core/check` | central differences, all branches, 5 and 7 parameters | 8.8e-10 |
| `python/check.py` | `../src/ddm_fast.py`, both series, range down to zero | 9.0e-10 |
| `python/check.py` | `fddm` at fixed start (`R/fddm_ref.R`) | 1.1e-8 density |
| `python/check.py` | `hddm_wfpt.full_pdf`, HSSM parametrization | 1.5e-11 |
| `R/ddmsz.R` | WienR from R | 4.8e-10 |
| `R/ddmsz.R` | `rtdists::ddiffusion` at precision 8 | 1.1e-7 |

Where a reference is looser than the core, the paper's high-precision checks decide: at the
worst rows a 40- to 50-digit mpmath reference agrees with this core to ten to twelve digits.

## Benchmarks

```bash
OMP_NUM_THREADS=1 python python/bench.py    # vs hddm-wfpt over 25 published parameter sets
OMP_NUM_THREADS=1 Rscript R/bench.R         # vs rtdists and WienR (slow: rtdists at precision 8)
cd python && python curve.py && cd ../R && Rscript curve.R && cd ../python && python plot_fig.py
```

Cost and accuracy always travel together: every package here is fast at three digits and slow
at ten, while this one runs at a fixed truncation of 1e-12 and returns the gradient as well.
